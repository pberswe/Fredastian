# AGENTS.md — Kid-friendly agentic game dev rules

## Goal
We are building a simple browser game together with an 11-year-old.
We will focus on story and game design. You (the agent) do the coding work.

## How you must work (agentic loop)
1) Restate the goal in 1 sentence.
2) Make the smallest code change to implement it.
3) Run: python scripts/verify
4) Tell us the result (PASS/FAIL) and paste the output.
5) Give 3 quick “play checks” for a kid to try in the browser.
6) If FAIL, fix and repeat until PASS.

## Constraints
- Keep the game as plain HTML + Canvas + JS (no new dependencies unless asked).
- One feature at a time (small, visible, fun).
- No big refactors.
- Prefer readable code and short functions.
